# ADR-0004: 里程碑门禁收口——焊死后门，配好钥匙

- 状态：已接受
- 日期：2026-08-15
- 背景：两轮流程体检（同日）——门禁太松（跨级跳/fail-open/表单后门）与门禁太死（gate 字段只能靠 AI 从拜访提取，失败即卡死）是同一枚硬币的两面，必须同批修复
- 关联：#25-#31；前置 ADR-0002（转化即定级是其后果条款的落地）

## 决策

### 1. 跨级推进校验途经全部 gate（#25）

`validateMilestoneAdvance` 从"只校验起点 gate"改为"校验 from→to 路径上每一道 gate"。M0 直跳 M8 需要过齐 M0-M7 全部 8 道门禁。

### 2. fail-closed（#25）

找不到 gate 配置时返回明确错误而非放行。配置缺失是异常态，应该修配置而不是裸奔。

### 3. 编辑表单禁改里程碑（#25）

ProjectForm 编辑态移除里程碑下拉（推进只走详情页/看板按钮，统一走 gate 校验）；新建态保留（配线索转化定级）。**门禁的严格性不允许和便利性共存于两个入口。**

### 4. 回退需确认 + 原因必填（#25）

`toStage < fromStage` 时要求 `backReason`（必填），时间轴留痕。回退往往意味着需求变化/报价被拒，是最该留证据的动作。

### 5. 阶段档案面板：gate 字段人工编辑入口（#27）

详情页新增面板：本阶段 gate 字段逐条展示**当前值 + 来源标记（AI/手动/暂无）+ 编辑入口**。人工值与 AI 值共用 applyConfirmedItem 写入通道（时间轴+变更历史留痕）；既有"AI 只写字段为空"的规则天然保证人工值不被 AI 覆盖。高频卡点字段（budget/price/firstContact）加正则兜底提取（照 M7 bidResult 先例）。

### 6. 单字段逃生门 manual-pass（#28）

gate 字段可"手动标记达标"，理由必填、时间轴留痕、字段值标记来源为 manual-pass。处理信息天然不从拜访来的场景（中标结果来自公告、决策链来自调研）。与跨级跳的本质区别：单字段豁免+证据化留痕 vs 整段绕过不留痕。

### 7. 转化即定级（#29，总纲决策⑥）

线索转化商机时按已确认证据核定初始里程碑：门禁 5/5 且证据充分 → 最高 M2（按 requirements/预算/决策链证据分档），否则 M0。时间轴补记定级依据。

### 8. 赢单/流失闭环（#30）

详情 drawer 提供赢单/流失操作（流失必填原因），打通 closedAt/status 流转——转化率③的分母自此可信。M8 赢单后引导复盘。

### 9. 前端 gate 规则单一真源（#25 顺带）

projects.tsx 手抄的 MILESTONE_GATES 改从 `@ai-sales/shared` 导入，消除前后端口径漂移。

## 后果

- 修完后建议跑数据体检：查现存 milestone 与证据链严重不符的项目（历史旁路产物），出清洗清单。
- manual-pass 的字段在指标统计中如实计数（不区分天然/豁免），后续如需"含豁免率"指标另议。
- 多来源提取（招投标回填/对话提取）进 backlog（#31）。
