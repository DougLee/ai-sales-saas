# ADR-0003: 商机推进工作台与详情页重设计决策

- 状态：已接受
- 日期：2026-08-15
- 背景：grill-with-docs 会话（依据设计稿《商机推进工作台》《商机详情页》20260813）
- 前置：ADR-0001/0002 同套模式；总纲决策 ⑧⑨⑩ 已拍板

## 决策

### 1. 范围：工作台 + 详情页全做

projects.tsx 列表区重写为 9 里程碑看板工作台；详情 drawer 改造（真假条 + 里程碑证据锚点条 + AI 作战室），一次对版设计稿。

### 2. 后端推导 + metrics

projects list 每条附带推导字段：停滞天数（staleDays）、等待状态（waitingStatus 已有）、决策链人数（decisionMap.nodes 数）、证据链数（evidenceCount = confirmed TimelineEvent 数）、下一步（nextAction = 最早未完成任务 + 截止）、疑似幻觉标记（illusion）。新建 `GET /api/projects/metrics` 六格指标：在途数 / 名义管线金额 / **脱水金额+脱水率** / 停滞数 / 合理等待数 / 转化率③（季度）。

### 3. 脱水率：规则折算（透明可解释，不依赖 AI）

```
脱水金额 = Σ(amount × 单单可信度)
单单可信度 = 证据覆盖比例 × 50% + 决策链≥2人 × 20% + 近14天有推进 × 30%（封顶 100%）
证据覆盖比例 = min(1, confirmed事件数 / (milestone+1))   // 每推进一个里程碑至少应沉淀 1 条已确认证据
```

### 4. 三视图：看板 + 列表 + 漏斗

执行总纲决策 ⑧⑩：看板 9 列横滚 + 三阶段折叠切换；列表视图保留升级；**漏斗图从 pipeline.tsx 并入工作台，pipeline 路由与页面废除**（重定向 /projects）。不做卡片拖拽（决策⑨），推进仍走详情页 Gate 流程。

### 5. 停滞与等待分家

- **合理等待**（紫标，不计停滞）：`waitingStatus` 非空（等预算/审批/招标/上会），显示恢复跟进日期。
- **停滞**（红标）：无 waitingStatus 且超 21 天未推进（updatedAt）。
- **疑似幻觉**（红虚线卡）：未处于等待态、超 15 天未推进、且 confirmed 证据链数为 0（"15 天无证据推进"）。

### 6. 沿用既有决策

商机不支持直接新建（页头无新建按钮，引导去线索）；「记一笔」统一录入面板（Batch 3.7）未落地前，详情页入口仍为「记录拜访」。

## 后果

- pipeline.tsx 废除后 `/pipeline` 路由重定向到 `/projects`，数据质量四看板入口需另行安放（后续 issue）。
- 脱水口径为 v1 规则，上线后如需引入 AI 判别另行 ADR。
- 详情页真假条的五格数据全部来自列表推导字段复用，无额外接口。
