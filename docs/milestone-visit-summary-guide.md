# 里程碑推进拜访摘要写法速查表

在 `/projects` 商机详情页点击「记录拜访」后，AI 会从拜访摘要中自动提取里程碑 gate 所需的结构化字段。摘要中**明确写出对应关键词**可以显著提高提取成功率。

## 速查表

| 当前阶段 | 目标阶段 | Gate 校验字段 | 拜访摘要中需要明确写出 |
|----------|----------|---------------|------------------------|
| M0 初识客户 | M1 明确痛点 | `humanInfo.firstContact` | 首次接触方式：电话 / 拜访 / 引荐 / 展会 |
| M1 明确痛点 | M2 明确需求 | `humanInfo.painPoints` | 具体痛点：师资不足 / 平台卡顿 / 管理困难 / 作业批改压力大 |
| M2 明确需求 | M3 明确经费 | `businessInfo.requirements` | 需求指标：覆盖学生数、功能要求、开课时间、学分要求 |
| M3 明确经费 | M4 明确方案 | `financeInfo.budget` | 客户预算金额或来源：如客户预算 50 万 / 专项经费 / 常规预算 |
| M4 明确方案 | M5 明确价格 | `businessInfo.solution` | 方案要点、实施计划、交付内容、客户反馈 |
| M5 明确价格 | M6 协助采购 | `financeInfo.price` | **我方报价金额**：如我方总报价 128 万（含税），分三期付款 |
| M6 协助采购 | M7 招标确认 | `decisionMap.nodes` | 决策链人物：姓名、职务、态度，建议用「①... ②...」列出 |
| M7 招标确认 | M8 投标中标 | `evidence.bidResult` | 中标/签约结果：如「已中标，金额128万」或「已签约，合同金额128万」 |

## 写作建议

1. **用明确的句式**：
   - 「首次接触方式为：电话」
   - 「客户痛点是：师资不足」
   - 「方案要点：①... ②... ③...」

2. **一条拜访可覆盖多个字段**：例如同时写清楚首次接触方式、痛点、需求，一次录入可满足多个阶段条件。

3. **避免模糊表达**：少用「沟通了一下」「聊了下」，多写具体事实。

4. **区分 budget 和 price**：
   - `budget` 是客户的预算，如「客户预算约 100 万」
   - `price` 是我方的报价，如「我方总报价 128 万元（含税）」
   - M3 校验 budget，M5 校验 price，不要写混。

5. **M4 示例**：
   > 本次向客户提交了基于 AI 通识课平台的定制化方案，已完成产品演示。方案要点：①校级统一开课平台；②配套 50 学时教师培训；③与教务系统对接；④分三年分期建设。客户总体认可，提出需要补充性价比对比。
